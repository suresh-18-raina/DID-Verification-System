An identity is a name plus a freshly generated Ed25519 key pair. Pick the role it will play.

What happens when you click

  1. An Ed25519 private and public key are generated.
  2. The DID is a hash of the public key, so only the key owner can prove it.
  3. A DID Document (public key only) is saved as a JSON file.
  4. The private key is saved as private_key.pem and is never shown or sent.
  5. A fingerprint of the DID Document is written to the ledger.
